# MISRA C 合规修复

扫描指定的 C 文件并修复以下 MISRA C 违规。

## 规则

### 1. 整数字面量添加 U 后缀
所有无符号整数字面量统一使用大写 `U` 后缀：
- 十进制: `0` → `0U`, `1` → `1U`, `100` → `100U`, `2500` → `2500U`
- 十六进制: `0xFF` → `0xFFU`, `0xFFFE` → `0xFFFEU`, `0xFFFFFFFF` → `0xFFFFFFFFU`
- 移位: `1<<8` → `1U<<8U`

### 2. enum 赋值给整数类型必须显式转换
enum 值赋值给 `uint16_t`/`uint32_t` 字段时加对应类型转换：
```c
// 正确
.index = (uint32_t)SOUND_NO_AUDIO,
.priority = (uint16_t)SOUND_PRIO_VALUE_MAX,
// 错误
.index = SOUND_NO_AUDIO,
```

### 3. 隐式有符号/无符号转换
替换隐式转换，所有混合类型赋值使用显式类型转换。

## 约束
- 不得修改代码逻辑，只添加后缀和类型转换
- 每个修复报告格式: `文件:行号: 修改内容`
- 修复完成后报告违规数量变化（修复前/修复后）
